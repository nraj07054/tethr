Your Android phone, on your Mac

Installing on the Mac

With Homebrew

Recommended, so brew upgrade keeps it current.

brew install --cask nraj07054/tethr/tethr
xattr -dr com.apple.quarantine /Applications/Tethr.app
The second line is not optional. Homebrew tags everything it installs, and macOS refuses to open a tagged app that Apple has not notarised — you would see “Apple could not verify ‘Tethr’ is free of malware.” Run it again after every brew upgrade, which re-tags the app.

Without Homebrew

One command, and nothing to clear afterwards.

curl -L -o /tmp/Tethr.zip https://github.com/nraj07054/tethr/releases/latest/download/Tethr-macOS.zip
unzip -q -o /tmp/Tethr.zip -d /Applications && open /Applications/Tethr.app
Downloading the zip in a browser instead will not work on its own — browsers apply the same quarantine tag. curl does not, which is why this route needs no extra step. If you already downloaded it in a browser, run the xattr line above once.

Why the warning happens at all

Tethr is signed ad‑hoc rather than notarised by Apple, because notarising requires a paid Apple Developer account this project does not have. That is the only message macOS has for an app in that position — nothing is damaged, and clearing the tag does not disable Gatekeeper, which still checks the signature. If you would rather not take that on trust, build it from source; it is one command and the result is identical.

Installing on the phone

  1. Open the Android download link on the phone. Chrome will warn that this type of file can harm your device — it says that about every APK, signed or not. Tap Download anyway.
  2. Open it from the download notification, or from Files → Downloads. Android asks whether Chrome may install unknown apps; allow it. Play Protect may offer to scan first — both prompts are normal for an app installed outside the Play Store.
  3. Grant the permissions it asks for. Each one buys a feature and nothing works silently without it: contacts, call log and phone for calls; SMS for messages; notification access for the shade; accessibility for controlling the screen; display-over-other-apps for the clipboard; and unrestricted battery so Android stops pausing the link.
Tethr is not on the Play Store and cannot be. Reading SMS needs READ_SMS, which Google grants only to a phone’s default messaging app — so Messages exists only because Tethr is installed directly.

Pairing

  1. Open Tethr on the Mac. It shows a QR code, and asks for Local Network access — the phone reaches the Mac over your LAN, and the link cannot work without it.
  2. Open Tethr on the phone and scan the code. That happens once. After that the two find each other on their own whenever both are on the same network.

What it does

Screen mirroring

The phone’s screen, live, in a phone-shaped window on the Mac.

Remote control

Click and drag to tap and swipe. Back, Home and Recents.

Calls

Call history, dial from the Mac, caller ID, and a floating call card.

Messages

SMS threads on a real keyboard. On a dual-SIM phone, replies leave from the right SIM.

Notifications

Mirrored with the real app name and icon, and repliable inline.

Clipboard

Copy on one, paste on the other. Password and one-time-code copies are left behind.

File transfer

Drag files onto the Mac, or share to Tethr from any Android app.

Contacts

The phone’s address book, synced across.

Security

  1. No account, no server, no cloud. The two devices talk directly over your network.
  2. Pairing happens once, by QR. The shared secret never crosses the wire again — each connection proves it knows it with an HMAC‑SHA256 challenge over two fresh nonces, so a recorded handshake is useless later.
  3. Everything after the handshake is encrypted with AES‑256‑GCM, keyed per connection and per direction, with counters that make replays fail.
  4. Unlinking is authenticated, so nobody on the network can unpair your phone by sending a packet.
Tethr reads your messages, contacts and call log, and can drive your phone. You should not take any of the above on faith — the source is public, and if you find something wrong with it, please open an issue.
